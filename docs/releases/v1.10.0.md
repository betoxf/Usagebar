## Follows the AI tool you are using

- Keep the last AI tool's usage in the menu bar when you switch to another app. The bar no longer jumps back to the provider you last clicked, so z.ai appears only after you use ZCode or a z.ai CLI.
- Follow AI CLIs in any terminal: Claude Code, Codex, Cursor Agent, Kimi, and Grok. Claude Code pointed at the z.ai or Kimi gateway shows that provider.
- No new permission. Usagebar reads the foreground command of your terminal sessions and keeps none of it.

## Less background work

- Close provider connections after each refresh. Idle connections were waking the app several times a second between refreshes.
- Stop writing cookies and cached responses to disk.
- Refresh enabled providers that are not on screen five times less often, and immediately when they are shown or the menu opens.
- In ten-minute runs on one Mac with four providers enabled, CPU time fell from 0.86 to 0.31 ms per second and wakeups from 1.24 to 0.39 per second. Results vary with providers and network.

## Good to know

- New sign-ins are picked up within ten minutes, or at once when you click **Refresh**.
- An editor that had no terminal session when it came forward is checked again the next time you switch to it.
- Claude Code set up for z.ai through `~/.claude/settings.json` rather than the environment shows as Claude.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
