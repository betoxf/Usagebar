## No keychain password prompt for z.ai

- Read the z.ai Keychain key through macOS's own `security` tool instead of in the app. Updating Usagebar no longer brings up a password dialog for that key.
- A keychain dialog that is left unanswered no longer holds up the other providers. Before, the menu bar showed **Setup** until it was answered.
- Read the key once per launch instead of every five minutes.

If your z.ai key was added to the Keychain some other way than with `security`, macOS may ask once on behalf of `security`. Choose **Always Allow** and it will not ask again, including after updates.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
