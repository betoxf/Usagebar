## Cursor and Grok are back as one card

- Cursor 3.28 encrypts its sign-in on disk, which hid Cursor. Usagebar now reads the Cursor Agent CLI's sign-in instead, so the Cursor card with the xAI, Grok, Cursor and Grok Bot marks returns, and bringing Grok Bot to the front selects it again.
- Grok on unified billing with Cursor no longer shows a second XAI card with the same usage; the Cursor card stands for both.
- The menu bar shows the Claude spark and the Codex logo, the same marks as the panel.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.11.1...v1.11.2)
