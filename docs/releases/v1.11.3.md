## Claude plans without a five-hour limit

- Some Claude plans no longer have a five-hour limit, and Usagebar showed them a 5h reading of 0% that didn't exist. The menu bar and panel now show only the limits your plan has.
- Plans that still have the five-hour limit look the same as before.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.11.2...v1.11.3)
