## Easy setup

- Usagebar now sets up in one window. If it finds no sign-in on first launch, the window opens by itself. Click **Sign In** next to each tool you use, and it shows **Connected** on its own, with no Refresh.
- Until something is connected, the menu bar shows the Usagebar logo above **Setup**. Click it to open the window. Later, **Connect More Tools…** is under the panel's **⋯** button.
- The old window that asked you to copy a session cookie from DevTools is gone.

## Plan names in the panel

- Claude's card now shows your plan, such as **Pro**, **Max**, or **Ultra**, instead of how you signed in.
- Codex reads **Pro Lite** instead of "Prolite", and z.ai shows its plan when it reports one.
- XAI no longer shows an email address where the plan goes.

## Kimi Code

- Kimi Code now has its official logo, color, and name.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.11.3...v1.12.0)
