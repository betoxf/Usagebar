## XAI removed

- Usagebar no longer tracks XAI on its own. Its card could appear with an error when xAI's billing service was down, even when Grok runs on your Cursor plan.
- Grok usage stays on the Cursor card, and Grok apps and the Grok CLI show Cursor in the menu bar.
- Usagebar no longer contacts xAI or reads Grok's sign-in.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.12.0...v1.12.1)
