## Cursor's weekly reading during outages

- When Cursor's weekly usage couldn't be read, the card fell back to the monthly figure, so a spent weekly allowance could show as 0%. It now keeps your last weekly reading, with a "Couldn't refresh weekly usage" note, until that reading's reset time.
- Plans without a weekly allowance work as before.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.12.1...v1.12.2)
