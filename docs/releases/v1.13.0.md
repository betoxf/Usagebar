## DeepSeek

- Usagebar now shows DeepSeek, with its official logo. DeepSeek is prepaid, so the menu bar and panel show the amount you have left instead of a percentage, and the card lists granted credits beside it.
- Sign in to DeepSeek Harness and Usagebar finds it on its own. With an API key, click **Add Key** in the setup window. Usagebar also reads `DEEPSEEK_API_KEY` or `api_key` in `~/.deepseek/config.toml`.
- If a request fails, the card keeps your last amount, or shows `--` before the first reading, so a failure never looks like an empty balance.
- With Follow Active App on, DeepSeek Harness, the `dsh` and `deepseek-tui` CLIs, and Claude Code pointed at DeepSeek all show DeepSeek in the menu bar.

## Add keys in the setup window

- **Add Key** on the z.ai and DeepSeek rows now opens the row in place with a field, **Paste**, and **Save**. z.ai no longer sends you to edit a config file.
- A pasted key is encrypted on your Mac and comes first for that provider. **Forget Saved z.ai Key** and **Forget Saved DeepSeek Key** under the panel's **⋯** button remove it.
- When z.ai or DeepSeek rejects a key, the card says so and links to its row, so you can replace the key.

## Privacy

- With a Harness sign-in, Usagebar reads DeepSeek's balance from the same private endpoint as Harness's account page, and only sends that sign-in to `platform.deepseek.com`. That endpoint can change without notice. API keys use DeepSeek's documented balance endpoint.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
