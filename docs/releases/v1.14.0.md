## Qwen

- Usagebar now shows Qwen for the QwenCloud Token Plan. The menu bar shows the 5-hour window beside the weekly one, or the monthly one when your plan has no weekly window, and the panel lists each window with its reset time and your plan.
- Click **Sign In** on the Qwen row in the setup window. QwenCloud opens inside Usagebar; sign in with Google, GitHub, or an email code, and the window closes on its own.
- Token Plan API keys can't read their own limits, so Usagebar keeps the QwenCloud console session instead, encrypted on your Mac. **Sign Out Qwen** under the panel's **⋯** button removes it.
- With Follow Active App on, Claude Code pointed at the QwenCloud gateway and the `qwen` CLI show Qwen in the menu bar.

## Fixes

- While you're in the Claude app, the menu bar no longer switches to Codex when the ChatGPT or Codex app turns active in the background without showing a window. Each refresh also puts back the provider of the app in front if the bar drifted from it.
- The panel's refresh arrow now spins in place instead of jumping to the top of the panel and flickering.

## Privacy

- Qwen usage comes from the private gateway behind QwenCloud's own Token Plan page (`home.qwencloud.com` and `cs-data.qwencloud.com`), which can change without notice. The session is sent only to QwenCloud.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
