## Fixes

- While you're in the Claude app, the menu bar no longer switches to Codex when one of Codex's background helpers, such as its computer-use service, turns active. Helpers without a Dock icon no longer move the menu bar, even when the Codex app isn't open.

## Connections

- **Connect More Tools…** is now **Connections…**. It's always under the panel's **⋯** button and opens one window with every tool.
- Click **Connected** on a row, then **Disconnect**, to stop showing that tool. Disconnecting forgets what Usagebar saved for it (a browser session or a pasted key) and leaves a CLI's own sign-in alone. Click **Sign In** to connect it again; if the CLI is still signed in, it reconnects at once.
- The separate **Sign Out** and **Forget Saved** menu items are gone; **Disconnect** replaces them.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
