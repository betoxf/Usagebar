## Fixes

- Usagebar can no longer sign you out of Claude Code or Codex. It used to refresh their sign-ins with their own refresh tokens and keep the new tokens to itself, so the next time Claude Code or Codex refreshed, its token no longer worked and you had to log in again.
- Usagebar now only reads what Claude Code and Codex saved, and never contacts their sign-in servers. When a sign-in has expired, the card keeps your last reading and says **Open Claude Code to renew its sign-in** (or Codex). Using that tool renews it, and Usagebar picks it up on its own.
- Usagebar's own encrypted copy of Claude's sign-in no longer keeps Claude Code's refresh token.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
