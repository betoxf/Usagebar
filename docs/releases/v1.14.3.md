## Look

- The panel now has a solid background, light or dark with your Mac, and its cards use the same tint and border as the Connections window. The blurred desktop no longer shows through it.
- The Usagebar mark in the panel's header is drawn with a bolder line.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.

[Full changelog](https://github.com/betoxf/Usagebar/compare/v1.14.2...v1.14.3)
