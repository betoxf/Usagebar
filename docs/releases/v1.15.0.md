## Stay signed in

- Claude Code's and Codex's access tokens expire every few hours, but their sign-ins last weeks. Usagebar used to treat an expired token as an ended sign-in. Now, when only the token has expired, the card keeps your last reading and says it's waiting for the tool to renew it, with no login button.
- When you open the panel or click **Refresh**, Usagebar asks Claude Code (`claude -p /usage`) or Codex (`codex app-server`) to renew the token. The tool renews it and saves it where it always does. Usagebar still never uses their refresh tokens, nothing is sent to a model, and no session or terminal is opened.
- **Sign In Again** appears only when a sign-in has really ended. It runs `claude auth login`, `codex login`, `cursor-agent login` or `kimi login` in Terminal, and the card updates as soon as the login finishes.

## Offline

- When the Mac is offline, the panel shows one "No internet connection" notice instead of an error on every card and keeps the last readings. Usagebar refreshes on its own when the connection comes back.

## Clicks

- Either click on the menu-bar item opens the panel. Pick the provider to show in the bar from the panel; clicking the item no longer switches providers.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
