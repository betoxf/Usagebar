## Stay current without clicking

- Usagebar now keeps Claude Code's and Codex's sign-ins renewed in the background. It asks Claude Code to renew a few minutes before its access token expires, and asks either tool as soon as a refresh finds the token expired, so the card no longer says it's waiting for a renewal until you open the panel.
- The waiting note appears only when a renewal fails. While it keeps failing, Usagebar tries again less often, up to every half hour; opening the panel or clicking **Refresh** tries again right away.
- Usagebar still never uses Claude Code's or Codex's refresh tokens, nothing is sent to a model, and no session or terminal is opened.

## Update

Use **Check for Updates** under the panel's **⋯** button, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
