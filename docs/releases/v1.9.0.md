## Lower background CPU use

- Reuse unchanged menu-bar images and build menus when opened.
- Keep credential discovery and parsing off the UI thread, cache availability, and avoid rewriting unchanged credentials.
- Stop login polling and pending extraction when the login window closes.
- Stop background usage requests for hidden providers; refresh a provider when it is enabled again.

## Power and refresh behavior

- Keep the normal two-minute refresh interval. In Low Power Mode, refresh at least five minutes apart and pause automatic provider rotation.
- Pause requests and rotation while the display or Mac sleeps, then refresh stale usage on wake.
- Retry failed providers less frequently and honor server retry deadlines, including during manual refresh.
- Keep the last successful reading after a failed refresh. The new **Last Updates** submenu shows each provider's freshness and retry delay.

## Also included

- Automatically show z.ai usage when ZCode is the active app and Follow Active App is enabled.
- A universal app for Apple silicon and Intel Macs running macOS 14 or newer.
- Regression coverage for scheduling, cancellation, timer cleanup, menus, and image caching.

## Update

Use **Check for Updates** in Usagebar, or run:

```bash
brew update && brew upgrade --cask usagebar
```

New installations:

```bash
brew install --cask betoxf/tap/usagebar
```

You can also download `Usagebar.zip` below, quit Usagebar, replace `/Applications/Usagebar.app`, and launch the new copy. Release artifacts continue to use the existing non-notarized distribution method described in the README.
